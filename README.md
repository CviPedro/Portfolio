# Portfólio do Pedro

Site de uma página feito com React, TypeScript e Vite. As seções deslizam da esquerda para a direita conforme você rola a página, e uma linha roxa na lateral mostra o progresso.

## Como rodar

Precisa do Node.js 20 ou mais novo.

```bash
npm install
npm run dev        # abre em http://localhost:5173
npm run typecheck  # só confere os tipos
npm run build      # gera a pasta dist/ para publicar
```
